    Monta el laboratorio paso a paso

    Antes de empezar necesitas

    • Docker Desktop instalado y encendido.
    • Git instalado.
    • Una cuenta de GitHub (gratis).
    • El zip del proyecto que te entregó el docente.
    • Unos 10 GB libres y conexión a internet (se descargan imágenes grandes).
